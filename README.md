# HelpDesk Analytics Platform

End-to-end IT Service Desk analytics platform.

## Overview

This project analyzes IT Service Desk incidents and provides
business intelligence through an automated ETL pipeline,
relational database, REST API and interactive Power BI dashboards.

## Technologies

- Python
- Pandas
- PostgreSQL
- SQL
- FastAPI
- Power BI
- Docker
- Git
- GitHub

## Architecture

CSV / Data Sources
        ↓
Python ETL
        ↓
PostgreSQL
        ↓
FastAPI
        ↓
Power BI
